# Oren Portfolio

Static GitHub Pages build for the Oren portfolio site.

## Deploy

1. Push this folder to a GitHub repository.
2. In the repository, open Settings -> Pages.
3. Set Source to "Deploy from a branch".
4. Select the `main` branch and `/root`.
5. Save and wait for the Pages URL to appear.

Keep `index.html`, `overrides.css`, `editable-config.js`, `overrides.js`, and `assets/` together at the repository root.
